# ADR-001: Initial Technology Stack

## Status
Superseded in part by ADR 001 (Next.js Framework Adoption)

## Context
Pronnova requires a web application, persistent data storage, authentication, and AI-assisted processing.

The project needs a maintainable architecture suitable for incremental implementation by a university team.

## Decision
The initial technology stack is:
- Next.js / React for the frontend (see `001-nextjs.md`)
- Supabase for database and authentication

## Consequences
The frontend will use Next.js App Router for user interface and client workflows.
Database access, authentication, and AI processing must follow the approved architecture.
Backend implementation and additional libraries will be evaluated in subsequent ADRs.
