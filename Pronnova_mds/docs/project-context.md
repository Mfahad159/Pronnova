# Project Context

## 1. Project Overview

Pronnova is a pronunciation assessment and adaptive
learning system designed for Pakistani Grade 1 students.

The system aims to support teachers in identifying
pronunciation difficulties and providing appropriate
practice exercises.

## 2. Problem Statement

Young students may struggle with correct pronunciation
during early language learning.

Teachers need a practical way to assess pronunciation,
identify errors, and monitor student progress.

Pronnova aims to provide AI-assisted pronunciation
assessment and structured learning support.

## 3. Target Users

### Primary Users

- Teachers
- Grade 1 students

### Secondary Users

- Administrators, if required by the approved scope

## 4. Core Functionality

The planned system includes:

- Teacher-managed pronunciation exercises
- Difficulty levels: Easy, Medium, Advanced
- Student speech recording
- Comparison against expected pronunciation
- Pronunciation scoring and error identification
- Teacher dashboards and student progress tracking

Detailed functionality will be defined in individual
feature specifications.

## 5. Project Scope

The initial implementation will focus on a selected
subset of approved FYP use cases.

The implementation scope must remain consistent
with the approved requirements and evaluation plan.

## 6. Technology Stack

- React for the frontend
- Supabase for database and authentication

Backend architecture and additional technologies
will be finalized before implementation.

## 7. Development Approach

The project will use AI-assisted development through
Antigravity.

Implementation will follow a specification-first,
incremental development workflow.

All generated code must be reviewed, tested, and
understood by the development team.
