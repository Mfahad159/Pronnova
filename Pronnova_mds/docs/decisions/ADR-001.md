# ADR-001: Initial Technology Stack

## Status

Accepted

## Context

Pronnova requires a web application, persistent data
storage, authentication, and AI-assisted processing.

The project needs a maintainable architecture suitable
for incremental implementation by a university team.

## Decision

The initial technology stack is:

- React for the frontend
- Supabase for database and authentication

## Consequences

The frontend will use React for the user interface
and client-side interactions.

Database access, authentication, and AI processing
must follow the approved architecture.

The backend implementation and additional libraries
remain undecided.

## Pending Decisions

- React project setup
- Zustand and frontend state management conventions
- API client and data fetching approach
- Database schema
- Authentication implementation
- Audio processing and AI assessment design
